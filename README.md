# NetSentinel

## Intelligent Network Behavior Monitoring System

NetSentinel is a network monitoring and behavior analysis system designed to capture, analyze, and identify unusual patterns in network traffic.

The project combines practical Computer Networks concepts with data analysis and intelligent anomaly detection to provide a deeper understanding of network behavior.

## Current Focus

The current development focuses on building a reliable network monitoring core:

* Network packet capture
* Packet parsing and protocol analysis
* IP, MAC, port, and connection analysis
* Network traffic statistics
* Network behavior monitoring
* Rule-based suspicious activity detection
* Structured storage of network observations

## Future Scope

The system is intended to evolve toward more intelligent and advanced monitoring capabilities, potentially including:

* Machine learning-based anomaly detection
* Behavioral profiling of network hosts
* Detection of unusual traffic patterns
* Real-time monitoring dashboard
* Network activity visualization
* Historical traffic analysis
* Alert generation and reporting
* Advanced intrusion detection capabilities

## Technology Stack

### Core Technologies

* **Python** — Primary implementation language
* **Git & GitHub** — Version control and project collaboration

### Potential Technologies

Depending on the implementation requirements, the project may incorporate:

* **Scapy** — Packet capture and packet-level analysis
* **PyShark** — Network packet analysis
* **Pandas** — Traffic data processing and analysis
* **Matplotlib / Plotly** — Data visualization
* **Scikit-learn** — Machine learning and anomaly detection
* **SQLite / PostgreSQL** — Persistent storage of network observations
* **Flask / FastAPI** — Backend API, if a web-based interface is adopted

The final technology stack will be determined during implementation based on the project's requirements and design decisions.

## Project Status

🚧 **Under Development**

NetSentinel is being developed as an academic Computer Networks project with an emphasis on practical networking, network behavior analysis, and intelligent detection.

## Project Vision

NetSentinel aims to evolve from a network monitoring system into an intelligent platform capable of understanding normal network behavior and identifying potentially suspicious deviations.
